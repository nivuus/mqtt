# Règle de Contribution : Sois Indépendant

- Implémente chaque fonctionnalité de façon autonome, sans dépendre d'autres modules sauf nécessité absolue.
- Découpe chaque logique dans des fichiers et classes distincts, pour faciliter la maintenance et la réutilisation.
- Prends des initiatives pour compléter, corriger ou améliorer le code sans attendre de validation.
- Utilise des noms explicites pour chaque entité, classe, fichier et dossier.
- Ne laisse jamais un module dépendre inutilement d'un autre : privilégie l'injection de dépendances ou l'utilisation d'interfaces.
- Documente chaque classe et méthode pour garantir la compréhension sans contexte externe.
- Supprime tout code ou log inutile dès qu'il n'est plus requis.
- Teste chaque module indépendamment avant intégration globale.

Respecte cette règle dans tout le projet.
